# 05: 도넛 차트

Spec: `.scratch/poll-deadline-charts/spec.md`

**What to build:** Operator는 Option이 5개 이하인 Poll에 Chart Type으로 도넛을 고를 수 있다.

- **도넛 모양**: Option마다 색이 다른 조각이 있고, 가운데에 총 표 수가 보인다. 범례에는 Option별 색, 텍스트, 표 수, 퍼센트, "내 선택" 표시가 있다.
- **표가 0개일 때**: 빈 링과 "아직 표가 없습니다"가 보인다.
- **Option 6개 이상**: 폼에서 도넛을 고를 수 없고, 서버도 거부한다.

구현 결정:
- `createPoll`이 도넛을 받는다. Option 수가 도넛 상한(5)을 넘으면 `too-many-options-for-donut`으로 거부한다. 상한은 기존 제한값 상수와 함께 둬서 클라이언트 폼도 같은 값을 쓴다.
- 도넛은 서버 렌더링 SVG로 그린다. 라이트·다크 모드 모두에서 구분되는 5색 고정 팔레트를 쓰고, 색만으로 구분하지 않도록 범례에 텍스트를 함께 적는다.
